项目总览

让奖项、人生与时代一起翻页

五个模块共用同一批诺贝尔奖数据——获奖记录、论文元数据、OpenAlex 引用指标——但分别切入五个不同的问题：获奖者的地理流动、学术生命周期的节奏、合作网络的形态、研究主题的迁移、以及代表作与长尾产出的对比。每个模块都是独立页面，前后翻页即可依次浏览。

成员 A 地缘政治与获奖者空间轨迹
成员 B 学术生命周期与产出节奏
成员 C 合作网络与内部引用
成员 D 研究主题的迁移与跨界
成员 E 代表作的长尾影响力
数据源
  • Scientific Data 出版的 Nobel laureate publication records dataset（1900–2016），含论文标题、DOI、发表年份、引用数
  • Kaggle 下载的获奖者基础个人信息总览，含出生地、所属机构、获奖理由等
  • 诺贝尔奖官网获取的获奖者照片
  • OpenAlex API 通过 DOI 查询获得的论文拓展数据，含 FWCI、引用百分位等指标
  • Zenodo（10.5281/zenodo.20301326）获取的地缘政治数据集，用于分析获奖者的跨国迁移路径
数据处理
  • 将 OpenAlex 返回的论文数据与获奖记录按 DOI 及作者姓名匹配，标记每篇论文是否为获奖代表作
  • 将论文分配到 OpenAlex 微观主题分类（4,500+ 个主题），追踪主题随年代的迁移与跨界
  • 通过论文作者与诺贝尔奖得主的姓名缩写、机构、年份进行多维度匹配，建立得主论文全量时间线
  • 每个学科优先保留获奖代表作和高引用论文，再按分层抽样补充长尾论文
  • 前端只加载聚合与抽样后的数据集，原始全量论文表不进入浏览器

收束页

前往斯德哥尔摩，数据背后的发现

五个模块从不同角度切入同一批诺奖数据。汇总下来，有几点值得记住。

诺贝尔奖得主的生存环境存在显著的空间不平等——大多数获奖者集中于少数几个国家的少数机构。 获奖前后存在明显的产出模式差异：许多人的代表作发表在获奖前 5–10 年，而非获奖之后。 得主之间的合作关系跨越年代和学科，形成一张稀疏但连接紧密的合作网络，团队规模在近几十年明显增大。 诺奖论文的研究主题持续迁移，传统学科分类之下存在大量跨学科交叉，物理、化学、医学的边界并不牢固。 少数论文占据了引用的大头，绝大多数论文位于长尾之中——代表作的影响力往往是其余论文的数十倍。

大家知道怎么成为诺贝尔奖得主了吗？

首先，得想办法进一所高产的研究机构。数据显示得主们高度集中在少数几个国家的顶尖院所——这些地方才是学术生产力的核心枢纽。然后，要趁年轻多发论文，统计表明许多人的代表作发表在获奖前五到十年，而不是获奖之后，35–45 岁可能是你的黄金创作窗口。

记得跟对合作者——得主之间的合著网络比你想象的更紧密，跨年代的师承关系也相当常见。如果觉得自己的研究太冷门，别担心——诺奖论文的研究主题跨起界来毫不含糊，传统的物理、化学、医学三分法之下，研究主题早就越界到处串门了。最后，哪怕你一辈子只发了一篇高引论文，也比百篇无人问津的强——获奖者论文的平均引用常常是其余论文的几十倍。

所以，大家要努力争取诺贝尔奖——虽然好像是不加综测分的。
